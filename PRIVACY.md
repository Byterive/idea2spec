# idea2spec privacy

This page says what idea2spec does with your data. It applies to idea2spec version 0.1 and later releases of that line, until a newer version of this file replaces it. Date: 2026-11-13.

## What it reads
What you tell it about your idea, and the files in the folder where you run it. The research agents also read public web pages and APIs, such as Hacker News, GitHub, the App Store search, Steam, npm and Wikipedia.

## What it writes and where
Local files in `idea2spec/<NNN-slug>/` in the folder where you ran it: `interview.md`, `00-evidence.md`, `01-decision.md` and, only when the verdict is GO or you record an override, `spec.md`. `/idea2spec:export` writes a stories folder or an issues list as local files, and only when you ask. It shows you the folder path and waits for your yes before the first file is written.

## What it sends and to whom
idea2spec is Markdown only, with no scripts and no hooks. Its agents use web search and page fetch, so your idea text, or a generalised version of it, reaches search providers and the sites above. The first question lets you choose: generalised search terms only (the default), your exact wording, or no web search at all.

It does not publish, post, email or upload anything, and it never asks for passwords, keys or tokens. How long a search provider keeps a query is set by that provider.

## How long data is kept
Your files stay in your project folder until you delete them. idea2spec keeps nothing anywhere else.

## Who it is for
We do not design idea2spec for people under 18, and we do not knowingly collect data from them.

## Other software
idea2spec runs inside Claude Code. Claude Code and the other tools it works with handle your data under their own terms. This page covers only idea2spec.

## Contact
Use the contact details on [byterive.com](https://byterive.com). We do not publish an email address for privacy questions yet.
